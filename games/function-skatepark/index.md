## How to play

1. In **Build park**, edit each equation and its start and end x values. Leave a bound blank for infinity; ranges can overlap or leave gaps.
2. Pick a starting x position, then press **Play**.
3. Ride with the keyboard or the on-screen buttons.

| Key | Action |
| --- | --- |
| Left / Right | Push |
| Down | Brake, or get ready to grind |
| Up | Ollie (double tap: kickflip) |
| Z / X / C / V | Kickflip / heelflip / 360 shuvit / varial flip |
| Up + Left or Right | Pop shuvit |
| 1–6 | 50-50, boardslide, noseslide, tailslide, nosegrind, 5-0 |
| Option / Escape / R | Play or pause / pause / reset the board |

On a touch screen, use the Push, Ollie, Kickflip and Brake buttons.

Your equations and settings are saved in your browser on this device.
